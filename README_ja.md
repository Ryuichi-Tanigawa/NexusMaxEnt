# NexusMaxEnt™

2D-DOSY NMRスペクトル再構成のための最大エントロピー法（MaxEnt）解析ツール

---

## 主な特徴（プロモーション用CPU版）
- **高度なNMRデータ処理**: PALMA、GIFA、およびClassic MaxEntの手法に着想を得た最適化アルゴリズムを搭載。
- **ADMM Mirror CPU版を同梱**: 機能評価およびプロモーションを目的とした、無償利用・再配布が可能なCPUベースの最適化モジュールを収録（※その他の商用CPU/GPU版アルゴリズムは本配布物には含まれません）。
- **インストーラーによるワンステップ環境構築**: 必要な依存関係をすべて内包した専用インストーラー形式で提供されるため、Python本体の手動インストールや煩雑なライブラリ設定は一切不要です。

---

## 動作要件
- **対応OS**: Windows 11 (64-bit 推奨)
- **実行環境**: 自己完結型環境（専用インストーラーよりセットアップ）

## 使用方法およびデータ準備

### 1-A. Bruker TopSpin でのデータ前処理
**bpp-ste-led** シーケンス（例: `ledbpgp2s`）を用いて測定された **1H DOSY NMRデータ** を対象としています。
- エクスポートを行う前に、1D/2Dにおいて適切な位相補正（例: `apk`）を完了させてください。
- F2軸のデータ点数（`SI`）を約 8192 ポイントに設定します。
- F1軸のデータ点数（`SI`）を F1軸の `TD` と一致するように設定します。
- **`xf2`** および **`abs2`** を実行し、**`2rr`** ファイル（直接観測軸のみフーリエ変換・位相補正された実数データ）を生成してください。

### 1-B. JEOL Delta でのデータ前処理
バイポーラ磁場勾配パルスシーケンス（例: `bpp_led_dosy` または同等のBPP-STEシーケンス）を用いて測定された **1H DOSY NMRデータ** を対象としています。
- 直接観測軸（F2 / X軸）のみにフーリエ変換（FT）を適用してください。
- エクスポートを行う前に、適切な位相補正を完了させてください。
- F2軸のデータ点数を約 8192 ポイントに設定します。
- 処理済みの2Dデータセットを **JEOL Generic形式** でエクスポートし、ペアとなる **`.hdr`** ファイルおよび **`.bin`** ファイルを生成してください。  
*(※GUIの画面キャプチャを交えた詳細な操作手順については、同梱のユーザーマニュアルをご参照ください)*

### 2. 必要な実験パラメータの読み込み
解析に必要な主要パラメータ（**`d20`**, **`p30`**, **`d16`**, **`difflist`**）はデータから自動抽出されます。*(※万一パラメータの自動取得に失敗した場合でも、GUI上から手動でのフォールバック入力が可能です)*

### 3. アプリケーションの起動と実行
1. 提供されたインストーラー（.exe）を実行し、画面の指示に従ってお好みのディレクトリにインストールしてください。
2. インストール先ディレクトリを開き、`NexusMaxEnt.exe` を起動します。  
*(※日常的に使用する場合は、デスクトップにショートカットを作成しておくと便利です)*  
3. 前処理済みのデータセット（Bruker TopSpinの測定ディレクトリ、JEOL Genericファイル群、または `.npz` ファイル）を読み込みます。

---

### 4. b値の計算式とパルスシーケンスに関する重要事項
本ツールは、**bpp-ste-led** シーケンス（例: `ledbpgp2s`）を前提として拡散磁場勾配のb値を計算します。

`b_value = gamma^2 * difflist^2 * 4 * p30^2 * (d20 - 2*p30/3 - d16/2)`

- **`p30`**: バイポーラ磁場勾配パルス対における **単一のPFGパルス幅**（Little Delta / 2）として定義されます。
- **`d20`**: Big Delta（拡散時間、秒単位）。
- **`d16`**: 磁場勾配パルス後のリカバリー遅延時間（Gradient recovery delay、秒単位）。

*【ノンバイポーラ型シーケンス（標準的なSTE等）に関する注意点】*  
シングルPFGパルスを用いるノンバイポーラ磁場勾配シーケンスで取得されたデータを処理する場合は、Little Deltaの定義が異なります。`p30` および `d16`（磁場勾配リカバリー遅延）のパラメータ設定に十分ご留意ください。

## 入力データ形式 (`.npz`)

測定装置からの直接読み込みのほか、データを直接流し込める **NumPy圧縮アーカイブ形式（`.npz`）** をサポートしています。

### 入力 `.npz` のデータ構造（キー名）
入力する `.npz` ファイルには、以下のキーとデータ配列が含まれている必要があります：
- **`data`**: 2次元配列、形状 `(N_f1, N_f2)`（F1 × F2 の強度マトリクス。例: 2rrデータ）
- **`axis_f1`**: 1次元配列、形状 `(N_f1,)`（F1軸の値）
- **`axis_f2`**: 1次元配列、形状 `(N_f2,)`（F2軸の化学シフト値、ppm単位）
- **`difflist`**: 1次元配列、形状 `(N_f1,)`（磁場勾配強度のリスト）
- **`d20`**: float（Big Delta、秒単位）
- **`p30`**: float（単一PFGパルス幅 p30、マイクロ秒単位：Little Delta / 2）
- **`d16`**: float（磁場勾配リカバリー遅延、秒単位）

*※独自形式のデータであっても、簡単なPythonスクリプトや生成AIを活用することで容易に入力用 `.npz` ファイルを作成・変換できます。*

---

## 出力データ形式（解析結果）

解析完了後にエクスポートされる結果ファイル（`nexus_maxent_result.npz`）は以下の厳密なデータ構造に従っており、Pythonスクリプト等から対応するキーを指定して簡単に読み込むことができます。

### 出力 `.npz` のデータ構造（キー名）
- **`dosy_matrix`**: 2次元配列、形状 `(N_diff, N_f2)`（再構成されたDOSY強度マトリクス）
- **`lap_axis`**: 1次元配列、形状 `(N_diff,)`（拡散係数軸の値、m²/s単位）
- **`axis_f2`**: 1次元配列、形状 `(N_f2,)`（F2軸の化学シフト値、ppm単位）
- **`d20`**, **`p30`**, **`d16`**: float（解析時に使用・継承された各実験パラメータ）

### 独自プロット・ビューア開発の自由度
出力結果は標準的な `.npz` 形式で保存されるため、標準的なPythonライブラリ（NumPy, Matplotlib, Plotly, PyQtなど）や生成AIツールを活用して、研究室独自のプロットスクリプトを作成したり、目的に応じたインタラクティブなGUIビューアを自由に構築して解析データを二次利用することが可能です。
